# Вебсайт для архитектурного лейбла СМОЛА

SPA, написанное на React+TS, с использованием препроцессора SCSS. Изначально был выбран Tailwind, однако, в процессе, решил отказаться от него и переписал проект под SCSS.

[Ссылка на макет в фигме](https://www.figma.com/design/kPSonr2SyKw6pL0ULBMfzk/Untitled?node-id=0-1&p=f&t=ilZWv6oGBhB4MF52-0)

## Технологии

React 18+, TypeScript 5+, SCSS, Vite 5+, деплой на Vercel; ранее Tailwind v4

## Установка и запуск

# Клонирование

```bash
git clone https://github.com/didu4/smola-website.git
```

# Установка зависимостей

```bash
npm install
```

# Запуск сервера

```bash
npm run dev
```

# Сборка

```bash
npm run build
```

# Превью сборки

```bash
npm run preview
```
